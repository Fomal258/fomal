# RING ROSTER

`https://ringroster-ekznddff.manus.space/` 와 같은 화면을 VS Code에서 직접 고칠 수 있게 정리한 프로젝트입니다.
원본(Manus 스타터)의 로그인·서버·구글 드라이브 저장을 걷어내고 필요한 코드만 남겼습니다.

- React 19 + Vite + TypeScript (의존성: react, react-dom, lucide-react)
- 소스 파일 11개 / CSS 1,780줄 / 빌드 결과 약 262KB
- 기능: 이름 검색(자동완성) · 정렬(기본/최신 등록순/오래된 등록순/A-Z/Z-A/찜) · 이름 첫 글자 필터 · 찜 · 열 수 조절 · 선수 추가/수정/삭제 · 이름/링크 여러 개(드래그 순서 변경) · 사진 자르기(위치·크기) · 디자인 편집
- 라이브 사이트와 1440px 전체 화면 픽셀 비교: 동일 (하단 저장 안내 문구 1줄만 "이 브라우저에 저장됩니다"로 변경)

## 사이트를 보는 방법

| 방법 | 할 일 | 특징 |
| --- | --- | --- |
| ① 바로 보기 | `roster-standalone.html` 더블클릭 | 설치 없이 브라우저에서 열림. CSS·JS가 한 파일에 포함 |
| ② 개발 모드 | `npm install` → `npm run dev` → http://localhost:5173 | 코드를 고치면 화면이 바로 바뀜 |
| ③ 빌드 결과 | `npm run build` → `dist/` | 배포용 결과물 |

수정 후 ①도 갱신하려면 `npm run build:single` 을 다시 실행하세요.

## 선수 추가/삭제 · 이름/링크 여러 개

**선수(이름) 추가/삭제**
- 추가: 헤더의 `선수 추가` 또는 그리드 마지막의 `+ 선수 추가하기` → 이름 입력 후 저장
- 이름 수정: `로스터 편집` → 카드 클릭 → 이름 변경 → 저장
- 삭제: 같은 팝업에서 `삭제` (확인창 1회)

**이름·링크 여러 개 (같은 방식)**
- `로스터 편집` → 카드 클릭 → **이름** 목록과 **링크** 목록에서 줄 추가/삭제
- 순서 변경: 줄을 **드래그 앤 드롭** 하거나 `↑` `↓` 버튼
- **이름은 첫 번째가 화면(카드)에 보이는 이름**입니다. 예전 데이터의 단일 이름은 자동으로 목록으로 변환됩니다
- 이름은 여러 개 중 어느 것으로 검색해도 찾아집니다
- 링크는 주소만 입력하고, 표시 이름은 주소에서 자동 생성됩니다 (`youtube.com` → YouTube)

| 링크 수 | 카드(프로필 이미지) 클릭 시 |
| --- | --- |
| 0개 | 선수 정보 팝업 |
| 1개 | 새 탭에서 바로 이동 |
| 2개 이상 | 카드 옆 선택 팝업 (Esc·바깥 클릭으로 닫힘) |

선수 이름을 눌러 여는 정보 팝업에도 등록된 링크가 순서대로 나열됩니다.

## 정렬 · 이름 첫 글자 필터

- 정렬: 기본순 · **최신 등록순** · **오래된 등록순** · A-Z · Z-A · 찜한 선수 · **랜덤**
  - 최신/오래된 순은 등록 시각(`createdAt`)을 기준으로 합니다. 기존 129명은 등록 시각이 없어 원래 순서를 유지합니다
  - 랜덤은 시드 기반 셔플이라 화면을 조작해도 순서가 흔들리지 않고, 옆의 **다시 섞기** 버튼으로 새 순서를 뽑습니다
- 이름 필터: 정렬 옆 줄에서 `전체 · # · A ~ Z · 기타` 중 하나를 고르면 그 글자로 시작하는 선수만 표시
  - 해당 글자에 선수가 없으면 칩이 비활성화됩니다
  - 검색어와 함께 적용되고, 켜져 있으면 해제 전까지 선수 추가 카드는 숨겨집니다
  - 모바일에서는 한 줄 가로 스크롤로 동작합니다

## 사진 위치·크기 조절 (크롭)

`로스터 편집` → 카드 클릭 → **이미지 선택** 후, 카드와 같은 4:5 박스에서 사진을 맞춥니다.

- **크기**: 슬라이더 **50~250%** — 100% 미만은 사진이 작아지고 여백이 생깁니다
- **위치**: 사진을 드래그하거나, 박스를 클릭한 뒤 **방향키로 1px 씩 이동** (`Shift` + 방향키 = 10px)
- **가운데 스냅**: 드래그 중 가운데에서 3% 안쪽이면 자동으로 0%에 붙고, 빨간 안내선과 "가운데 맞춤" 배지 표시
  - 방향키 이동은 정밀 조작이라 스냅하지 않습니다
- **가운데 · 원본 크기**: 한 번에 초기화
- 이동 가능 범위는 사진이 프레임을 벗어나지 않는 만큼으로 제한됩니다 (확대 시 가장자리, 축소 시 안쪽)
- 값은 `imageCrop: { x, y, zoom }` 로 저장되어 카드·정보 팝업에 그대로 적용되고 새로고침 후에도 유지됩니다

## 사진 넣는 방법 (브라우저 상관없이 보이게)

**핵심**: 업로드한 사진은 그 브라우저 저장소에만 남습니다. 여러 브라우저·PC에서 똑같이 보이게 하려면 **파일로 넣으세요.**

1. `client/public/photos/` 폴더에 사진을 넣습니다.
2. 파일명은 선수 이름과 비슷하면 됩니다. 띄어쓰기·대소문자·언더스코어는 자동 처리되고, 아래 순서로 찾습니다.
   - ① 정확히 같은 이름: `1 Called Manders.jpg`
   - ② 이름으로 시작(접미사 허용): `1-called-manders-2.jpg`, `aaron williams 2026.jpg`
   - ③ 이름을 포함: `wwe-crazzy-steve-2026.jpg`
3. `npm run photos` 실행 (또는 `npm run dev` / `npm run build` 시 자동 실행) → `photos/index.json` 갱신
4. 로스터 편집 → 카드 클릭 → **사진 파일 (photos 폴더)** 에서 고르거나 **이름으로 찾기** 클릭

- 파일 기반 사진은 빌드 결과물(`dist/photos/`)에 함께 들어가므로 **모든 브라우저·PC에서 동일**하게 보입니다
- 업로드(이미지 선택)한 사진은 `data:` URL로 그 브라우저 저장소에만 남습니다
- 단일 HTML(`roster-standalone.html`)에서도 `photos` 폴더를 같은 위치에 두면 그대로 표시됩니다

## 사진 목록이 비어 있을 때 (선택 안 함만 보임)

목록은 `photos/index.json` 을 읽어서 만듭니다. 아래를 확인하세요.

1. **파일 위치**: `client/public/photos/` 안에 사진이 있어야 합니다. (하위 폴더는 읽지 않습니다)
2. **목록 생성**: `npm run photos` 실행. `npm run dev`·`npm run build` 때도 자동 실행됩니다.
3. **배포본(dist) 사용 중**: `dist/photos/` 안에 사진과 `index.json` 이 있어야 합니다 → `public/photos`에 넣고 다시 빌드 후 폴더째 업로드.
4. **단일 HTML 사용 중**: HTML 파일 옆에 `photos` 폴더(사진 + `index.json`)가 있어야 합니다.
5. **확장자**: `jpg jpeg png webp gif avif` 만 목록에 들어갑니다. iPhone HEIC는 JPG로 변환하세요.
6. 목록이 없어도 편집 팝업의 **파일명 직접 입력**으로 경로를 넣을 수 있고, **목록 새로고침** 버튼으로 다시 읽을 수 있습니다.

## 오늘의 선수 뽑기

정렬 셀렉트 옆 **오늘의 선수 뽑기**(주사위) 버튼을 누르면 명단에서 한 명을 무작위로 골라 정보 팝업으로 보여 줍니다.

- 뽑을 때마다 직전 선수는 피해서 다시 뽑습니다
- 팝업 안 **다른 선수 보기** 버튼으로 바로 다시 뽑을 수 있습니다
- 팝업 상단 문구는 `TODAY'S PICK`, 애니메이션·배경·테두리는 프로필 팝업 디자인 설정을 그대로 따릅니다
- 모바일에서는 버튼이 아이콘만 표시됩니다(접근성 이름은 유지)

## 프로필 팝업 디자인

`디자인 편집` → **프로필 팝업** 에서 설정합니다. (선수 이름을 눌렀을 때 열리는 정보 팝업)

| 항목 | 설명 |
| --- | --- |
| 팝업 배경 | 단색 / **그라데이션**(시작색·끝색·각도 0~360°) / **이미지 업로드**(10MB 이하) |
| 배경 어둡게 | 0~80% — 배경 위에서 글자가 묻히지 않게 검은 막을 덮습니다 |
| 테두리 색 | 색상 선택 |
| 테두리 두께 | 없음 / 1px / 2px / 3px |
| 팝업 글자색 | 배경이 어두우면 흰색으로 바꿔 주세요 |

- 값은 `design.ts` 의 `profileModalBgMode`, `profileModalGradientFrom/To/Angle`, `profileModalBgImage`, `profileModalBorder`, `profileModalBorderWidth`, `profileModalOverlay` 에 저장됩니다
- 편집 중에는 미리보기 카드에 팝업 샘플이 함께 표시됩니다
- 기본값은 기존과 같습니다: 단색 `#ffffff`, 테두리 없음

## 팝업 애니메이션

`디자인 편집` → **프로필 팝업** 에서 열림/닫힘 효과를 고릅니다.

| 항목 | 값 |
| --- | --- |
| 열림 애니메이션 | 없음 / **페이드 인** / **슬라이드 업** / **확대** |
| 애니메이션 속도 | 100~800ms (20ms 단위) |

- 열 때와 **닫을 때** 같은 효과가 반대로 재생된 뒤 실제로 닫힙니다 (`ProfileInfoModal.tsx`의 `closing` 상태)
- `애니메이션 미리보기` 버튼으로 미리보기 카드에서 바로 확인할 수 있습니다
- 값은 `design.ts`의 `profileModalAnimation`, `profileModalDuration`에 저장되고 새로고침 후에도 유지됩니다
- 운영체제에서 "동작 줄이기(prefers-reduced-motion)"를 켠 사용자에게는 애니메이션이 자동으로 꺼집니다
